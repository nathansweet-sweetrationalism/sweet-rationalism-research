# Sweet Rationalism Research Archive

Public, version-controlled research editions of Nathan Sweet's articles.

**Canonical publication:** [SweetRationalism.com](https://sweetrationalism.com/). Files here record exact WordPress article HTML for provenance and historical diffing; cite and link to each article's canonical website URL except when citing a specific historical Git commit. **This repository does not supersede the website** and is not an independently hosted duplicate SEO site.

**Scope:** Only articles individually visible in the site's public articles list. Hidden/unlisted, noindex, draft and restricted posts are never ingested, exposed or reindexed. Existing independent Github+Zenodo deposits of the core RCF/ontology/ethos documents stay authoritative.

**Method:** In each audit distinguish documented evidence, interpretation, reductio, ethical risk warning, and demonstrated harm. Preserve the most pointed language warranted, never fictionalize quotes, observations, DOIs, or a rival's commitments. Store claims, dependencies, rivals, prediction and loss conditions, not final conclusions immune to correction.

**License:** Copyright © Nathan Sweet. Existing article-specific license terms, if any, govern; public archiving does not imply a separate license.
